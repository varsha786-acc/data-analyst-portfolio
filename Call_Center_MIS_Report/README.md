
# Call Center Operations & Performance MIS Report

## Project Overview
An Excel-based MIS reporting project designed to analyze call center operations, agent performance, customer satisfaction, and service efficiency.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- Slicers
- Excel Charts
- Data Cleaning

## Key KPIs
- Total Calls: 5,000
- Answer Rate: 81%
- Resolution Rate: 73%
- Average Speed of Answer: 67.52 seconds
- Average Satisfaction Rating: 3.40
- Abandoned Calls: 946

## Key Features
- Agent-wise performance analysis
- Topic-wise call analysis
- Monthly call trends
- Hour-wise call volume
- Customer satisfaction analysis
- Interactive dashboard with slicers
- MIS report and analytical insights
